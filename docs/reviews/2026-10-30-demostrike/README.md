# DemoStrike source review snapshot — paused

This is a publication-preparation copy based on public DemoStrike main commit 69a0bfc6dc885cee0cd02514003a3d8c9ee7066c. It is incomplete and is for manual review only, not a runnable or tested release. It is not the exact tested build: personal machine-specific path prefixes were replaced in 10 included files, and local demo fixtures were excluded. The SHA-256 of each original and review copy is recorded in review-manifest.json. The tested candidate and its evidence remain intact locally.

The package contains changed/new candidate Rust service and SQL source, Cargo manifest and lock, existing renderer adapters, and source tests/oracles. Existing unchanged source, UI, dependencies and license files from the base commit are not duplicated here. Raw demos, generated binaries, personal profile/database data, TLS keys, runtime logs and full ledgers are excluded. Full ledgers are local-only because they contain machine-specific details. Ten startup-related files from the 80-file review inventory are intentionally omitted, including the held dispatcher and redirector, preload/vite adapters, and startup/login test sources. The separate five-file held patch is not published. The omitted dispatcher means these modules are not integrated on this branch. Several retained files refer to excluded local fixtures; csdm_cli_demo.rs has a compile-time include_str! pointing to a redacted local-only oracle and the demo-dependent tests cannot run. Redaction changes path/authority literals and could change comparisons or authorization behavior; it is not behavior-preserving. This snapshot does not authorize or replace production startup registration. The unchanged lib.rs registers ImportQueue, not this product service. The React/TypeScript UI and transitional Go analyzer remain; the all-Rust goal is unfinished. Several download/video jobs, user profiles and normal initialization remain unsupported or unverified.

## Selected verified results and bounds

- The PG80 and PG87 owned original-renderer initialization tests exercised bounded empty-job owners, a real owned PostgreSQL history writer, retained client and reconnect. They do not prove general-profile behavior or nonempty download/video jobs.
- PG82/85/86 verified owned tag create/edit/delete paths, with original Settings interactions in PG85/86. Deletion and settings persistence are non-atomic in failure cases.
- PG92/95 exercised an original match/demo row and tag dialog with synthetic DOM actions on a public demo; this does not establish complete renderer parity.
- PG96 verified isolation of two owned product-service profiles/databases; association of the TLS peer with the owned process is an exclusive-key inference, not socket-to-PID attestation.
- PG99 used an original dialog component harness through the product Tauri adapter, not the complete original AppLoader.
- PG104 verified direct product deletion, settings cleanup, callback completion and owned disconnect; renderer-side processing/order was not tested.
- PG106 verified multi-peer loopback deliveries and cleanup; async write-failure equivalence and real renderer processing remain unverified.
- PG107–109 compared player-tag product transactions with the original source-derived Node handler against separate owned databases. In the tested repeated-ID boundary, 32767 pairs succeeded and 32768 returned an error and rolled back; PG109 showed DELETE occurred before the error in each path. Other oversized shapes and unchecked JSON inputs remain unverified. The applied-source suite reported 153 passed/35 ignored in the library and 20 passed/1 ignored in other suites; the reviewed copy is redacted and was not tested.

PG97 final database state is unknown and WebView release unverified; PG98 database state is unknown. PG101 browser denial remains in force. No release, merge or new normal-profile test is implied.
